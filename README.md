# Data Analytics Portfolio

Welcome to my portfolio. This is a modern, responsive web app built with React + Vite to showcase my dashboard and analytics work in a GitHub-inspired interface.

## Key Features
- GitHub-style portfolio layout with a clean repository-inspired UI.
- Project cards with filter support by category/tag.
- Direct links to live Tableau dashboards and source repositories.
- Project details modal for quick preview.
- Contribution-style activity graph section.
- Responsive design for desktop and mobile.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/jatinverma2007/dva_profile.git
   ```
2. Move into the project folder:
   ```bash
   cd dva_profile
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
